
# Indian Equity Portfolio Risk & Return Analysis

## Business Problem

Investors need to understand the relationship between
historical returns and investment risk when evaluating
a diversified equity portfolio.

This project analyzes historical stock price data to
evaluate performance, volatility, and risk-adjusted returns.

## Objectives

- Analyze historical stock performance.
- Calculate annualized returns and volatility.
- Compare risk-adjusted performance.
- Evaluate portfolio diversification.
- Compare optimized and equal-weighted portfolios.
